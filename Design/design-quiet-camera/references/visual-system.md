# 视觉规范

## 色彩

以下值来自已完成探索稿；用户更新稿优先。

| Token | 值 | 用途 |
|---|---|---|
| camera.background | #090A0A | 相机背景、取景外围 |
| camera.surface | #191B1B | 参数面板、焦段选中底色 |
| camera.border | #343737 | 分隔线、快门外圈 |
| camera.text.primary | #F4F3EE | 主要文字、图标 |
| camera.text.secondary | #A5AAA7 | 参数名、次级说明 |
| camera.accent | #F45135 | 快门、当前值、活动指示线 |

- 使用实色和少量表面层级，不默认引入大面积渐变、发光、重投影或玻璃质感。
- 让快门成为最大的橙红色块，其余强调色保持小面积。
- 将品牌色与状态语义区分：橙红快门不等于录制或错误；涉及录像、失败或警告时加文字或形状，并确认该功能存在。
- 图像上的焦段组可用近黑、约 88% 不透明度底色；不要降低整个组的 opacity，避免文字也被削弱。

## 字体

| 角色 | 基线 | 扩展规则 |
|---|---|---|
| 界面文字 | SF Pro Regular / Medium / Semibold | 自然句式、清晰层级 |
| 参数与刻度 | IBM Plex Mono Regular | 统一小数位、单位与数字对齐 |
| 中文说明 | Noto Sans SC Regular / Medium | 用于 Figma 注释；原生 iOS 中文沿系统回退 |
| 展示板标题 | SF Pro 44；中文方向名 26 | 仅用于展示板，不移入相机 UI |

- 将探索中的 10–13 pt 仪表读数作为密度参考。生产关键文字通常从 13–17 pt 起步，按设备、字体与对比检查；这些建议不代表已通过可访问性认证。
- 使用 35 mm、1/250 s、ISO 100、−0.3 EV 等清晰形式。空间不足时分行显示参数名与单位，不丢失语义。
- 先核验字体与 style 是否可用。缺失时明确替代：系统无衬线用于界面、系统等宽用于参数，不静默替换。
- 减掉低价值信息比继续缩小、淡化更有效。

## 几何与图标

- 以 4 pt 增量组织间距，默认水平边距 20–24 pt。全宽照片可以贴边，控制仍遵守安全区。
- 以 24 × 24 pt 图标画布、约 1.35 pt 单线作为探索起点，按实际尺寸调整。
- 使用圆角线端与连接，保持统一光学尺寸。借鉴 Design Better 的几何组织，不复制 DB 标志，不把细线叠成装饰。
- 复用兼容图标；新绘制时用可编辑矢量或 SVG，不用字符或 emoji 冒充图标。
- 快门参考：80 × 80 pt 控制、78 pt 外圈、64 pt 橙红内圆。同心结构替代拟物高光。
- 面板圆角参考 20 pt，焦段底 18 pt，缩略图 5 pt。手机外轮廓 38 pt 属于展示容器，不是通用组件圆角。

## 照片

采用自然光、真实细节与克制色彩验证界面。可选安静建筑、街景、植物或日常瞬间，不把庭院图当成固定品牌资产。

比较方案时使用同一张照片；可读性检查再换亮天、暗景与高纹理背景。允许必要的局部遮罩，不修改用户拍摄内容来迁就 UI。
