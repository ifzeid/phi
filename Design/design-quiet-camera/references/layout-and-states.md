# 布局与状态

## 方向

| 方向 | 组织方式 | 适用情境 |
|---|---|---|
| B / 安静取景（默认起点） | 大取景、下缘焦段、底部快门与少量控制；参数按需展开 | 日常拍摄、新功能默认布局 |
| A / 精密仪表（可选） | 独立取景框、焦段与自动状态、ISO / S / WB / EV 参数行、快门 | 高频参数调整、明确要求仪表感 |

不要把 A 的常驻读数、B 的大取景和展开面板全塞进默认态。比较时让差异体现在信息密度与操作方式，不只是改色。

## 取景与控制

1. 按系统安全区、实际拍摄比例与可见取景范围布局，不用装饰性手机边框定义实际安全区。
2. 顶部只保留必要功能；RAW、闪光、比例、对焦等必须与真实能力对应。
3. 将焦段靠近画面下缘，并明确单位。24 / 35 / 50 是焦段示例，不意味着设备具有三个对应原生镜头。
4. 居中快门，两侧放最近照片与参数入口，固定热区与对齐，不随文案长度移动。
5. 展开参数时保持快门位置；优先使用控制区。如覆盖取景，明确这是临时覆盖，关闭后恢复完整构图。不要静默修改拍摄裁切。

## 参数面板

每次突出一个参数：名称、当前值、单位、刻度或选项、自动状态、关闭入口。仅在产品逻辑明确时加入重置、锁定。

### 曝光

- 区分曝光补偿与手动曝光。自动曝光时调整 EV，不等于直接修改所有 ISO 和快门值。
- 范围、步长、拖动方向从实际能力确定；无依据时标为待确认。−0.3 EV 不是永久默认值。
- 数值与指示线一致：显示 −0.3 时不能把零点仍画在指示线下。
- 深色面板配橙红当前值与活动线。自动、禁用、边界状态不只靠颜色。

### 白平衡与对焦

- 延续同一面板骨架，替换参数语义，不硬套 EV 刻度。
- 白平衡如有 Kelvin、Tint，明确单位、自动/手动关系与支持范围，未确认时不承诺可用。
- 对焦区分 AF/MF、对焦距离与镜头焦段，不混淆焦段和对焦距离。
- 手势、触觉与动画只作为建议，除非已有实现或用户确认。

## 状态

按任务选择必要状态，不为简单探索穷举全部状态。

| 状态 | 要求 |
|---|---|
| 默认 | 画面、当前值与可执行快门优先 |
| 选中/调节 | 结合文本、背景或指示线 |
| 自动 | 显示 AUTO，明确哪些参数由系统控制 |
| 不可用 | 给出原因及恢复路径，不只降低透明度 |
| 拍摄/保存 | 依据实际阻塞能力反馈，不暗示未支持的连拍 |
| 权限/失败 | 就近说明并给出下一步，不用黑屏冒充取景 |
| 相册为空 | 简洁说明和必要操作，不使用抢占页面的大插画 |

## 延展

- 相册：照片优先，选择与浏览工具分层；选中状态增加勾选或边界。
- 设置：同色板与字体，以清晰列表组织；不强行加入快门和仪表刻度。
- 横屏：按握持、主操作手和比例重新布置，不把竖屏旋转当成完成。
- 大文字和窄屏：减少并列、增加行高或改成展开，不无限缩小，不把 390 × 844 当成唯一设备。
